# Pocket3 小小Vlog训练营

这是一个中文儿童友好的 DJI Osmo Pocket 3 学习网站。站点为纯静态页面，不需要登录，不上传视频到服务器，学习进度、每日打卡、分镜和家长复盘都保存在本机浏览器 localStorage。

## 本地运行

直接打开 `index.html` 即可使用。也可以在当前文件夹启动静态文件服务器后访问。

## 页面

- 首页
- 今日任务
- 30天课程
- Pocket3基础操作
- Vlog思维训练
- 常见问题
- 拍摄任务生成器
- 分镜脚本模板
- 家长复盘表
- 安全与隐私提示
- 资料来源页

## 资料原则

课程内容按以下优先级整理并重新编写：

1. DJI 大疆官方 Osmo Pocket 3 页面、用户手册、下载中心、支持中心、入门指南。
2. 高质量摄影/Vlog 创作者公开文章。
3. 论坛、社区、Reddit、B站等用户讨论只用于提炼常见问题，不直接复制原文，且标注为经验建议。

见 `research.md` 获取完整资料整理。
